# Stan Constitution

## Article I: Source of Truth

The strategy playbook at `docs/strategy-playbook.md` is the source of truth for quarterly strategy sessions and related outputs.

## Article II: Documentation First

This repository stays documentation-first. Keep changes small, focused, and easy to review.

## Article III: Stable Language and Links

Preserve the existing Dutch/English terminology used in the strategy docs. Keep links relative and stable.

## Article IV: Repo Hygiene

When adding or changing top-level docs, update `README.md` and any linked files together.

## Article V: Spec Kit Alignment

When using Spec Kit artifacts in this repo, keep them aligned with the playbook and with the repo's lightweight documentation scope.

## Article VI: Minimal Tooling

Do not add tooling, automation, or code unless it clearly supports the documentation workflow for Stan.

## Amendment Rule

Any change to this constitution must be reflected in the related docs and kept consistent with the strategy playbook.
