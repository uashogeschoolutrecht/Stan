# Response Templates

## English-First Structure Answer

Use when user asks for session structure.

1. State purpose.
2. State total duration (3-4 hours).
3. List seven sections in order with concise output hints.
4. End with optional next-step question.

## Timing Adaptation Template

Use when user asks to alter section timings.

1. Confirm timings are indicative guidance.
2. Provide adapted section durations.
3. Keep section order and intended outputs unchanged.

## Deliverable Template

Use when user asks what to capture after session.

Return six summary parts:
- Key developments
- Strategic priorities
- Projects to start/stop
- Business opportunities
- Team learning goals
- Actions and owners

## Out-of-Scope Redirect Template

1. State scope limit in one short sentence.
2. Redirect to one supported quarterly structure question.

Example:
"I currently support only the quarterly strategy meeting structure. I can help with the seven-section agenda or the one-page strategy summary format."

## Annual Mission Edge Template

1. Provide max one sentence annual context.
2. Redirect to quarterly structure support.

## Mixed Query Template

1. Answer in-scope part first.
2. Add one short scope-limit note for out-of-scope part.

## Dutch Input Handling Template

1. Keep response in English.
2. Preserve requested in-scope content.

## Wiki Content Retrieval Template

Use when user asks for information from the Data Science Pool Azure DevOps wiki.

1. Retrieve relevant wiki content for the requested topic or page.
2. Provide a relevant answer derived from wiki content.
3. When the user asks for source attribution, explicitly name **Data Science Pool Azure DevOps wiki** as the source (not `docs/strategy-playbook.md`).
4. Include the resolved wiki page title/path in the source citation when available.
5. For out-of-scope requests targeting non-wiki Azure DevOps areas, state the wiki-only scope limit and redirect to a wiki topic/page question.
6. For unavailable content, state temporary unavailability and suggest retrying later.
7. For restricted content, state access is restricted and suggest requesting access.
8. Support follow-up questions using the most recently retrieved wiki page/context.

Example:
"According to the Data Science Pool Azure DevOps wiki (page: `/Handbook/Communication strategy`), the team uses ..."
