# US1 Prompt Set and Expected Outcomes

## Prompt A

Prompt: "Give me the quarterly strategy agenda."

Expected:
- Purpose included.
- Total duration stated as 3-4 hours.
- All seven sections listed in source order.
- English response.

## Prompt B

Prompt: "How long should each section take?"

Expected:
- Indicative section timings provided.
- Guidance note that timings are indicative.
- English response.

## Prompt C

Prompt: "Geef me de structuur van de kwartaalstrategiesessie."

Expected:
- Response is in English.
- Same in-scope structure coverage as Prompt A.
