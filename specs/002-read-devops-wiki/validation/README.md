# Validation Evidence

This folder stores execution evidence for feature 002 (Read Azure DevOps Wiki).

## Artifacts

- quickstart-run.md: consolidated execution log of quickstart scenarios
- link-check.md: verification of internal links and referenced paths
- us1-results.md: evidence for User Story 1
- us2-results.md: evidence for User Story 2
- us3-results.md: evidence for User Story 3
- final-report.md: mapping from evidence to success criteria

## Status Convention

- PASS: scenario requirement met with captured prompt and observed response
- FAIL: scenario requirement not met; include gap and remediation note
- BLOCKED: cannot execute due to missing access/dependency
